# 接上回覆試算表（約 5 分鐘）

網頁現在是「示範模式」，資料只存在自己的瀏覽器。照下面做完，報名和匯款截圖就會寫進
「2026下 全時間訓練呼召訓練 台中場 (回覆)」試算表。

## 1. 貼上程式

1. 打開回覆試算表，上方選單：**擴充功能 → Apps Script**。
2. 把 `Code.gs` 的內容整個貼上，取代原本的程式碼，按儲存。

## 2. 授權

1. 上方函式選單選 `setupCheck`，按「執行」。
2. 跳出授權視窗時選自己的帳號並允許（需要試算表和雲端硬碟權限）。
3. 執行記錄出現「欄位都找到了」就成功。這一步也會：
   - 在試算表最右邊加一欄「報名編號」
   - 在雲端硬碟建立「呼召聚會 匯款截圖」資料夾

## 3. 部署成網頁應用程式

1. 右上 **部署 → 新增部署作業**，類型選「網頁應用程式」。
2. 執行身分：**我**；誰可以存取：**所有人**。
3. 按部署，複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。

## 4. 貼回網頁

打開 `index.html`，搜尋 `const API_URL = '';`，把網址貼進引號裡：

```js
const API_URL = 'https://script.google.com/macros/s/…/exec';
```

## 之後改程式

改完 `Code.gs` 要 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」**，網址不會變。

## 隱私說明

- 名單牆只拿得到「名字、性別、是否已繳費」，電話和身分證字號不會傳到網頁。
- 匯款截圖存在你的雲端硬碟，預設只有你看得到，試算表裡存的是檔案連結。
- 從網頁報名的人不會經過 Google 表單；原本的 Google 表單仍可使用，
  兩邊的資料都在同一個分頁，名單牆也都會顯示。
